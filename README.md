# ICT401 Word-Guessing Game

**Student:** Grishma Raut | **Student ID:** 202571518

ICT401 Assessment 3 – a Python word-guessing game with a terminal version (CLI) and a window version (GUI, Tkinter). Both use the same `GameEngine` class.

## How to run
- Terminal version: `python cli_app.py`
- Window version: `python gui_app.py`
- Tests: `python tester.py`

## Files
| File | Purpose |
|---|---|
| engine.py | GameEngine class and file functions |
| cli_app.py | Terminal version of the game |
| gui_app.py | Window version of the game (Tkinter) |
| tester.py | Tests for the GameEngine (added for Assessment 4) |
| easy.txt, medium.txt, hard.txt | Word lists with hints, written by me |
| game history.txt | Saved results of finished games |
